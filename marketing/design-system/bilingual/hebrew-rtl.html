Fonts swap by script Fraunces → Noto Serif Hebrew (headlines); Nunito Sans → Assistant (body/UI). Load both; set per `lang` attribute, not per page.
Layout mirrors, meaning doesn't Hearts, chips, nav order and card anatomy flip with `dir="rtl"`. Emoji, logos and the wordmark never flip.
Numbers, times, prices stay LTR 10:30, ₪45, 0–8 embed as LTR runs inside RTL text (use dir="ltr" spans or Unicode isolates).
Hebrew is shorter and denser Don't design layouts that only survive with long English strings; test both. Months abbreviate as ח׳ (חודשים).
Voice carries over Feminine address (שמרי, נסי) — the app speaks to her directly in Hebrew too. Same no-pressure rules.
Search is bilingual Users type either language regardless of UI language; matching handles final letters (ם/מ) and prefixes (ב/ל/ה).
